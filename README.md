# 가계부

결제 알림(카드사·은행·네이버·쿠팡·문자)을 읽어 **몇 월 며칠, 어디에, 얼마**를 자동으로 적는 안드로이드 가계부 앱.
두 사람이 각자 폰에 설치하고, 내 구글 스프레드시트를 거쳐 한 장부로 합쳐 본다.

## 설치

1. 폰에서 [`가계부_v1.1.apk`](가계부_v1.1.apk)를 내려받아 설치한다.
2. `설치 안내.html`의 순서(A 구글 시트 준비 → B 설치·알림 접근 → C 앱 설정)를 따른다.
   구글 시트에 붙일 스크립트는 `구글시트_스크립트.gs`.

## 구성

- `_system/app` — 앱 소스 (자바 + WebView 화면 `assets/index.html`)
- `_system/build.py` — Gradle 없이 SDK 도구로 APK를 만드는 스크립트
- 자료는 폰 안 SQLite와 사용자가 직접 만든 구글 시트에만 저장된다. 다른 서버로 보내지 않는다.
