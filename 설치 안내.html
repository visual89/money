가계부 설치 안내

결제 알림을 읽어 자동으로 적는 부부 공용 가계부 · v1.3 · 순서대로 A → B → C

A. 구글 스프레드시트 준비 (한 사람이 한 번만, 약 5분)

  1. 구글 계정으로 새 스프레드시트를 만듭니다 (이름 예: 우리집 가계부). 회사 PC에서 구글 드라이브가 막혀 있으면 폰이나 집 PC에서 합니다.
  2. 메뉴 확장 프로그램 → Apps Script를 엽니다. 처음 보이는 내용을 모두 지우고, 같은 폴더의 구글시트_스크립트.gs 내용을 전부 붙여 넣습니다.
  3. 맨 위 const KEY = '여기에_암호를_적으세요';의 따옴표 안을 둘만 아는 암호로 바꾸고 저장(💾)합니다.
  4. 오른쪽 위 배포 → 새 배포 → 유형 선택(⚙)에서 웹 앱을 고릅니다.
    다음 사용자 인증 정보로 실행: 나 · 액세스 권한이 있는 사용자: 모든 사용자 → 배포.
  5. 처음에는 권한 확인 창이 뜹니다. 내 계정 선택 → '고급' → '(프로젝트 이름)(으)로 이동' → 허용.
  6. 완료 화면의 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사해 둡니다. 두 폰에 똑같이 넣을 주소입니다.
'모든 사용자'는 주소를 아는 사람이 접속할 수 있다는 뜻이고, 암호가 맞아야만 읽고 쓸 수 있습니다. 주소와 암호는 다른 사람에게 알리지 않습니다. 나중에 스크립트를 고치면 배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포를 해야 반영됩니다 (주소는 그대로).

B. 폰에 앱 설치 (두 폰 각각)

  1. 폰 크롬에서 https://github.com/visual89/money/raw/main/gagyebu.apk를 열어 내려받고, 받은 파일을 엽니다. '출처를 알 수 없는 앱 설치'를 묻는 창이 뜨면 허용합니다.
  2. 'Play 프로텍트' 경고가 뜨면 세부정보 더보기 → 무시하고 설치를 누릅니다 (플레이스토어에 올리지 않은 개인 앱이라 뜨는 안내입니다).
  3. 앱을 열고 설정 탭 → [알림 접근 설정 열기] → 목록에서 가계부를 켭니다.
  4. 스위치가 회색으로 막혀 있으면: 설정 탭 [앱 정보] → 오른쪽 위 ⋮ → 제한된 설정 허용 → 다시 3번.
  5. 폰 설정 → 배터리 → 가계부를 '제한 없음'으로 두면 알림을 놓치지 않습니다.

C. 앱 설정 (두 폰 각각)

  1. 내 이름: 남편 폰은 '남편', 아내 폰은 '아내'처럼 서로 다르게 저장합니다. 누가 쓴 돈인지 구분됩니다.
  2. 구글 스프레드시트 공유: 웹 앱 주소는 이미 들어 있습니다(v1.2부터 설치 파일에 포함). A에서 정한 암호만 넣고 [저장] → [지금 맞추기]. '완료 (올림 N건 · 받음 N건)'이 보이면 연결된 것입니다.
  3. 카드로 한 번 결제해 보고, 내역 탭에 자동 표시로 적히는지, 구글 시트 '가계부' 탭에 한 줄이 생기는지 확인합니다.

알아 둘 점

자동으로 읽는 알림롯데카드(디지로카)·우리카드·현대카드 앱 알림, 농협카드 카카오톡 알림, 네이버·쿠팡 앱 알림, 카드 승인 문자, 은행 입출금 알림
적지 않는 것광고, 결제예정·명세서 안내, 금액이 없는 알림(쿠팡 '배송 출발' 등), 가족끼리 주고받은 메시지
같은 결제 알림 2개카드사 문자와 카드 앱 알림, 네이버 알림과 카드 알림처럼 같은 결제를 두 곳에서 알리면, 같은 금액이 1시간 안에 올 때 따로 적지 않고 한 건으로 합칩니다. 두 알림 가운데 가장 자세한 내용이 '어디에 썼나요'에 적히고(예: 동원참치 (네이버스토어)), 내역을 누르면 받은 알림 원본이 모두 보입니다. (같은 앱이 같은 금액을 두 번 알리면 두 번 결제한 것으로 보고 따로 적습니다.)
읽는 알림앱을 따로 지정하지 않습니다. 어떤 앱·문자든 금액과 승인·결제·입금·출금·이체 같은 말이 있는 알림은 모두 적습니다. 광고·쿠폰·가격 안내와 가족·지인 대화는 적지 않습니다.
잘못 읽혔을 때내역을 눌러 가게 이름·분류를 고치면 됩니다. 고친 분류는 기억해서 다음부터 그 가게에 자동으로 붙습니다. 계속 틀리는 카드사는 내역을 눌렀을 때 보이는 받은 알림 문구를 알려 주면 규칙을 고칩니다.
공유가 맞춰지는 때결제가 자동으로 적힌 직후, 내역을 고치거나 지운 직후, 앱을 열 때. 인터넷이 안 되면 폰에 두었다가 다음에 올립니다.
시트에서 직접 고치기시트에서 손으로 고친 내용은 폰에 반영되지 않습니다. 고칠 때는 앱에서 고칩니다. 시트는 보기·집계용으로 씁니다.
새 버전 설치앱을 열면 새 버전을 자동으로 확인하고, 있으면 맨 위에 [업데이트] 버튼이 뜹니다. 누르면 앱 안에서 받아 설치하며 내역은 유지됩니다. 처음 한 번은 '이 출처 허용'과 설치 확인 창이 뜹니다. 앱을 '삭제'하면 폰 안 내역은 지워지지만, 시트에 올라간 내역은 [지금 맞추기]로 다시 받습니다.
